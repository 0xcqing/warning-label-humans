A single-line safety warning label that should come printed on every human
being, written for the make.fun bounty "Warning label for humans (one line,
big laugh)".

## The label

WARNING: May say 'we should do this more often' and mean it for the whole drive home.

## Run

    node main.ts

Set `MAKEFUN_OUTPUT_DIR` to choose the output folder (default `/output`).
The script writes the label plus a single newline to `<output>/entry.txt`.
